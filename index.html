Job Portal

The MERN Stack Job Portal is a full-stack recruitment platform developed to streamline the hiring process for students, recruiters, and administrators. Built with MongoDB, Express.js, React.js, Node.js, and Tailwind CSS, it features secure JWT authentication, role-based access control, company management, job posting, application tracking, recruiter dashboards, student profiles, resume management, and advanced job search with filtering. Recruiters can manage companies, post jobs, review applications, and update candidate statuses, while students can discover opportunities and monitor their application progress. The project demonstrates expertise in scalable architecture, RESTful API development, responsive UI design, secure authentication, and modern software engineering best practices..
